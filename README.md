# Посмотри в окно

Учебный проект Яндекс Практикума. Приложение позволяет смотреть видео с видами из окон, искать их по городу и времени суток, выбирать ролики из списка и загружать дополнительные карточки.

## Технологии

- HTML5 и семантическая разметка.
- CSS: Flexbox, логические свойства, псевдоклассы и псевдоэлементы.
- JavaScript: запросы к API, шаблоны карточек, поиск и пагинация.
- Локальные шрифты Fira Sans Condensed и Oswald.

## Выполненная работа

В готовое приложение добавлены стили по макету: расположение блоков, оформление видео и карточек, кастомные чекбоксы, состояния наведения, нажатия и клавиатурного фокуса. Реализованы прокрутка списка и ограничение длинного текста. HTML и логика JavaScript сохранены из стартового проекта.

## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/pravednovartem/posmotri-v-okno-ad.git
   ```

2. Откройте папку проекта в редакторе и запустите `index.html` через локальный сервер, например Live Server в VS Code.
3. Для получения видео требуется интернет и доступ к API `https://v-content.practicum-team.ru`.

Установка зависимостей и сборка не требуются.
