## Запуск

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/pravednovartem/posmotri-v-okno-ad.git
   ```

2. Откройте папку проекта в редакторе и запустите `index.html` через локальный сервер, например Live Server в VS Code.
3. Для получения видео требуется интернет и доступ к API `https://v-content.practicum-team.ru`.

Установка зависимостей и сборка не требуются.
